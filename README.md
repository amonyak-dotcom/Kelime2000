# Kelime2000 V4 - Derleme doğrulamalı sürüm

Bu sürüm APK derlemesinden ÖNCE 2000 kelimeyi uzak veri kaynağından üretir ve 2000 benzersiz kelime olduğunu kontrol eder. Derleme başarısızsa APK üretilmez.

GitHub deposunun **ana dizinine** ZIP içindeki tüm dosya ve klasörleri yükleyin. `.github/workflows/android.yml` dahil tüm dosyaları güncelleyin. ZIP dosyasını doğrudan yüklemeyin.

GitHub Actions > Android APK Derle > en son başarılı çalışma > Artifacts > Kelime2000-APK.

Uygulama ana ekranında gerçekten yüklenen temel kelime sayısı gösterilir.

ÖNEMLİ: 2000 kelime derleme sırasında internetten çekilir; veri kaynağı erişilemezse derleme durur. Şıkların anlamsal yakınlığı tüm 2000 kelime için tek tek doğrulanmış değildir.
